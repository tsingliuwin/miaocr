# 喵OCR v1.1.0

自 v1.0.0 以来的界面与引擎大版本更新。

## 界面

- **全新自绘标题栏**：整条可拖拽，置顶 / 设置图标按钮紧贴窗口控件左侧，双击最大化
- **Snipaste 风格选区**：截图覆盖层接管全屏 —— 未选中区域压暗、选区内保持原亮度实时跟随；十字参考线、8 倍放大镜（像素网格 + 坐标 + 取色）、实时尺寸徽标、四角手柄；多显示器与跨屏拖拽
- 引擎下拉改为浮动菜单：不再挤压布局，点击外部自动收起，选中项带勾选
- 启动不再弹出终端窗口，无安全警告干扰
- 状态栏稳定显示「就绪 · 上次耗时 · 间隔」；轮询间隔跟随内容变化自适应（静止时自动放宽到 1.26 秒省电，内容一动立即恢复高频）

## 识别引擎

- **新增 PP-OCRv6（ONNX 内置，高精）**：单模型覆盖 50 种语言（中日英 + 46 种拉丁语言），官方基准识别精度 81.3%（v5 mobile 为 73.7%）；屏幕文字、点阵字符、工业场景显著增强
- 保留全部 8 引擎：Windows 原生、PP-OCRv5 (MNN 极速)、PP-OCRv6 (ONNX)、PaddleOCR-json、RapidOCR-json、Tesseract、百度 AI Studio（云端）、macOS 原生
- 内置引擎模型在界面内一键下载安装；PP-OCRv6 模型走 ModelScope 国内源

## 其它

- 问 AI 功能暂时下线（后端与配置保留，后续版本恢复）
- 稳定性：修复选区放大镜拖尾、修复沙箱构建产物的文件写入「拒绝访问」问题

## 下载

- `miaocr.exe` — Windows x64，免安装直接运行；默认使用系统自带 OCR，可在引擎下拉中切换并一键安装 PP-OCRv6
